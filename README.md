# -Inferential_statistics
Análisis exploratorio e inferencial sobre la base de datos dynamic_pricing (Kaggle). Incluye verificación del TCL, intervalos de confianza, pruebas t, Z, F de Fisher y chi-cuadrado, más análisis de poder estadístico. Desarrollado en Python para la Tarea 2 del curso Métodos Estadísticos en la Ciencia de Datos y Analítica (UNAD).
