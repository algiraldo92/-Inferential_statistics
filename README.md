# Tarea 2 – Análisis Exploratorio e Inferencial
### Dynamic Pricing Dataset – UNAD

Análisis estadístico inferencial sobre la base de datos `dynamic_pricing.csv` (Kaggle), desarrollado en Python como parte de la Tarea 2 del curso **Métodos Estadísticos en la Ciencia de Datos y Analítica** (Código 203008072) de la Universidad Nacional Abierta y a Distancia (UNAD).

## Contenido del análisis

- **Paso 1:** Carga, exploración y limpieza de la base de datos (1,000 registros, 10 variables).
- **Paso 2.1:** Verificación empírica del Teorema Central del Límite (1,000 muestras, n=30).
- **Paso 2.2:** Intervalos de confianza al 95% para media, proporción y varianza.
- **Paso 2.3:** Pruebas de hipótesis para comparación de medias (t de Student) y proporciones (Z).
- **Paso 2.4:** Prueba F de Fisher para homocedasticidad, con Levene y Bartlett.
- **Paso 2.5:** Prueba chi-cuadrado de independencia entre variables categóricas.
- **Paso 2.6:** Análisis de poder estadístico y errores Tipo I y II.

##  Tecnologías utilizadas

- Python 3.12
- pandas · numpy · scipy · statsmodels
- matplotlib · seaborn

- ##  Objetivo

Analizar el comportamiento de las tarifas dinámicas y la duración de los viajes mediante técnicas de estadística inferencial, para fundamentar decisiones sobre asignación de flota, segmentación de clientes y estructura tarifaria.
